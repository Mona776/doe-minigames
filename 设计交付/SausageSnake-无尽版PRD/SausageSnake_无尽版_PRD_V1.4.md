# Sausage Snake 无尽版产品需求文档

V1.4  |  2026年10月18日  |  产品 程序 美术 音频 UI 测试

## 1 产品概述

腊肠狗自动前进，玩家用确认键控制顺时针转向，吃骨头得分、延长身体，在逐步加速和增加障碍的场地中挑战本地最高纪录。

本文定义正式开发和资源制作要求。原型用于体验玩法；正式 UI、美术、音频按第4–7章制作，奖励入账接入主项目服务。

### 阅读分工

程序看第2、3章及第5章动效；UI看第4、5章；美术看第6章；音频看第7章；测试按第8章验收。所有岗位共用第1章的屏幕与按键定义。

### 产品与硬件边界

- 显示屏为1.54英寸、240×240像素，正方形；所有画面按240×240原尺寸制作与验收。

- 无尽模式，一条命、不限时；达到三星后继续游戏。结束条件为碰撞、主动结束或场地没有空格生成骨头。无复活、道具、关卡或联网排行榜。

- 游戏区域200×200像素，10×10格，每格20×20像素；四周为实体墙。角色从中央附近朝右出发，初始化见第2章。

### 三个按键的职责

| 位置 | 选择键 | 确认键 | 返回键 |
| --- | --- | --- | --- |
| 游戏入口 | 切换两个选项 | 进入开始或说明 | 回小游戏菜单 |
| 玩法说明 | 无操作 | 开始游戏 | 回入口并选中说明 |
| 局内移动 | 暂停 | 所选方向向右转90° | 打开结束确认 |
| 暂停中 | 继续游戏 | 无操作 | 直接结束并结算 |
| 结束确认 | 切换选项 | 执行所选项 | 取消确认并返回原状态 |
| 结果页 | 无操作 | 再来一局 | 回游戏入口 |

倒计时中选择键、确认键无效，返回键可打开结束确认。玩家界面统一使用实机按键名称。仅供研发对照：确认键=B、选择键=A、返回键=C。

## 2 程序需求 移动与难度

### 输入与转向

**每按一次确认键，向右转90°。**

- 以按下沿触发，长按只算一次；松开再按，继续转向。有效按下次数不设上限。
- 按下立即更新所选方向和箭头。到移动时间才按当前方向前进一格；按键不额外移动、不重置移动计时。
- 输入与移动按发生顺序处理。反向选择不忽略，实际走进身体才判自撞；已发生的移动不回滚。暂停、倒计时、确认框和结果页不接收局内转向。

### 初始化、得分与增长

- 初始总长度3格，包含头、身体、尾各1格。头位于零基坐标(5,4)，身体和尾依次在(4,4)、(3,4)；初始朝右、0分、无障碍，场上有1根骨头。
- 每吃1根骨头得1分；累计第2、4、6……根触发增长，每次增加1格。总长度 = 3 + 向下取整（总骨头数÷2）。
- 不另设固定长度上限，但受场地剩余空间限制；达到最高难度或三星后仍继续增长。

| 本次移动 | 位置与长度的变化 |
| --- | --- |
| 未触发增长 | 头前进1格，尾巴沿原身体路径前进1格；总长度不变。 |
| 触发增长 | 头前进1格，尾巴留在原格；总长度增加1格。 |

**表现要求：在头尾之间增加身体格块，头和尾的图形尺寸不变。前脚跟头、后脚跟尾；直行拉长时前后脚间距增大，转弯时分别沿头尾路径移动。**

### 碰撞

- 头的下一格越出场地，或有障碍、未离开的身体，则本局结束。
- 普通移动时，允许头进入尾巴在本次移动中腾出的格子；增长时尾巴没有腾出原格，不能按空格处理。
- 碰撞时不将头移动进非法格，先播放碰撞反馈，再进入结算。

### 难度配置

| 总骨头数 | LV | 每格耗时 | 目标障碍段数 |
| --- | --- | --- | --- |
| 0–4 | 1 | 550 ms | 0 |
| 5–9 | 2 | 470 ms | 2 |
| 10–14 | 3 | 400 ms | 3 |
| 15–24 | 4 | 370 ms | 4 |
| 25–34 | 5 | 340 ms | 5 |
| 35–44 | 6 | 310 ms | 6 |
| 45–54 | 7 | 280 ms | 6 |
| 55及以上 | 8 | 250 ms | 6 |

吃到对应分数的骨头后立即升档，不重置分数、身体或方向，不中断移动；第8档后速度和目标障碍数量不再提高。

### 食物生成

- 新骨头只能生成在身体和障碍之外的空格；优先随机选择与头的横向格差绝对值加纵向格差绝对值≥3的空格，无符合条件的位置时放宽到任意空格。没有空格可放食物时，按“场地满”结束并按当前分数结算。

### 障碍生成

- 每段连续占3格，横向或竖向。升档只追加障碍至目标段数，旧障碍保持不动。不得覆盖身体或当前骨头；每个新增障碍格到头的上述距离必须>2，并避开当前行进方向正前方3格。

- 不同障碍段不能相邻，含对角相邻。将身体占格视为空地，仅检查障碍布局：全部空地连通，每格至少有两个上下左右相邻的空格。这不保证玩家被自身身体围住后仍能脱困。

- 每段最多尝试100次。找不到公平位置时允许少放，下一次升档再补；不强行放置、不搬动身体和食物。新障碍出现即参与碰撞，闪烁只是视觉提示。

## 3 程序需求 状态与结算

### 单局流程

小游戏菜单 → 游戏入口（开始／玩法说明）→ 3、2、1、GO → 游戏 → 结束反馈 → 结果页。再来一局从全新倒计时开始，返回则回到游戏入口。

3、2、1各显示1秒，GO显示0.5秒，之后进入移动。倒计时内角色不移动，顶栏隐藏，场地保持可见。游戏、暂停、确认和结果页不执行10秒无操作退出；入口和说明页沿用系统10秒无操作回主界面。游戏流程保持亮屏。

### 暂停与结束确认

- 选择键暂停后停止规则计时；选择键继续从原位置恢复，等待一个完整移动间隔，当前所选方向保留。暂停中返回键直接结束并结算，不再加第二层确认。

- 返回键在移动或倒计时中打开“结束本局？”；默认选中“继续游戏”，另一项“结束本局”。说明文案为“按当前成绩结算”。

- 确认框打开期间冻结规则计时、移动和转向，不累计后台时间；取消后恢复原状态及剩余时间，当前所选方向保留。若打开确认前已经发生碰撞，优先进入碰撞结束流程。

- 碰撞后播放900ms反馈再显示结果；主动结束、场地满直接显示结果。结果页出现后800ms内屏蔽确认键重开，返回键不受此限制。

### 奖励与最高纪录

| 总骨头数 | 星级 | 贝壳 | 神 |
| --- | --- | --- | --- |
| 0–4 | 0星 | 5 | 0 |
| 5–9 | 1星 | 10 | 1 |
| 10–14 | 2星 | 20 | 2 |
| 15及以上 | 3星 | 30 | 3 |

碰撞、主动结束、场地满均按本局总骨头数结算；倒计时中主动结束也是0星、5贝壳。奖励上限为30贝壳、神+3。

结果页显示总骨头数、三颗星的明暗状态、贝壳和最高纪录；神值后台结算。每局仅提交一次结算，主项目奖励服务负责实际入账及防重复发放。

最高纪录为本机本游戏记录，初始0；严格超过才显示“新纪录”，相等不提示。局内实时预览，结算时保存，重启后保留。强退或断电不恢复对局、不补发未结算奖励。

原型已提供最高分存档和结算消息；原型中的奖励数值不等于主项目账户已实际入账。

## 4 UI需求 页面与状态

以下为正式 UI 页面及状态，全部按240×240制作。按键行为以第1章为准；图标表达分数、星级和奖励，文字解释操作与结果。

| 页面 | 必须展示的信息 | 交互及变体 |
| --- | --- | --- |
| 01 游戏入口 | Sausage Snake及无尽版标识、最高纪录、开始游戏、玩法说明 | 开始／说明两种选中态；默认选中开始，无最高纪录时显示0。 |
| 02 玩法说明 | 每按一次确认键，向右转90°；每两根增长、碰撞结束、逐步加速、5/10/15得星 | 右转图示搭配短句，不拆成连按教程或独立教学关。 |
| 03 开局倒计时 | 3 → 2 → 1 → GO四个状态，静止场地 | 顶栏隐藏；数字不遮挡初始角色和行进路径；最后一秒仍可看清场地。 |
| 04 局内顶栏 | LV、本局骨头总数、三颗星位、BEST | 正常、升档“加速!”、超过纪录高亮三种信息状态；骨头数为本局累计总数。 |
| 05 暂停 | 压暗场地、暂停、选择键继续、返回键结束 | 两个直接操作提示，场地保留并压暗，无二级选择菜单。 |
| 06 结束确认 | 结束本局？、按当前成绩结算、继续游戏、结束本局 | 两种选中态；默认“继续游戏”。 |
| 07 本局结果 | 本局结束、总骨头、0–3星、贝壳、最高纪录或新纪录、确认键再来一局、返回键返回 | 同一布局覆盖4档奖励；新纪录是独立状态，可与任意星级组合。返回键返回入口。 |

### 局内信息优先级

左侧LV表示难度档位，不表示关数；骨头总数不归零。5、10、15根分别点亮第一、二、三颗星。获得第三颗星后保持三星，计分继续增长。

本局超过旧纪录后，BEST高亮并随当前分数更新。非得星升档时，“加速!”暂替BEST显示约1秒，随后恢复纪录信息；得星与升档同帧时优先呈现得星反馈。

### 结果页状态示例

覆盖0／1／2／3星与普通／新纪录的组合；按第3章奖励表显示。本局1分、旧纪录0分，也必须显示新纪录。

## 5 UI需求 组件与动效规格

### 统一视觉与版式

采用像素硬边、深蓝底、低对比棋盘格、青绿色边框、暖金色焦点、米白正文。建议色板：背景#081923，棋盘#0D2633/#123241，边框#66C7B5，分隔#244D58，强调#F3C04F，正文#F4EDD6，次要文字#8DA5AD。颜色不能成为区分状态的唯一依据。

标题、按钮和提示文字距屏幕边缘至少12像素。游戏场地按专用坐标布置：200×200，左上角(20,30)，墙线放在场地外围，不挤占格子。顶栏在场地上方。正文12像素、标题24像素，采用可合法交付的像素字体；文字不烘焙进背景，数字字段预留到五位且不得互相覆盖。

| 组件或资源 | 制作规格 |
| --- | --- |
| 标题和背景 | 标题在160×48像素区域内排版；入口角色用正式部件拼接。棋盘底可用40×40平铺纹理或程序绘制，文字独立排版。 |
| 按钮和弹窗 | 按钮尺寸：入口138×26，结束确认142×26，结果142×28；提供普通/选中态。结束确认弹窗184×154，暂停弹窗170×90；边框与底可伸缩。 |
| 计分及奖励图标 | 骨头、贝壳各16×16；星星提供未获得/已获得两态，9×9用于顶栏，整数3倍用于结果页。 |
| 按键与方向图标 | 确认、选择、返回三类按键提示，按实机标识设计，图标建议16×16；局内方向箭头10×10，支持四向；教程右转图标18×18；不另做连按组合教程图标。 |
| 倒计时与字体 | 3/2/1建议在28×36区域内；GO使用24像素字号。交付所用字库及授权说明，覆盖正文中文、ASCII、数字和标点。 |

### 动效由程序驱动

| 事件 | 时序与效果 |
| --- | --- |
| 食物与得分 | 食物出现约250ms弹出；平时每600ms上下浮动2px。吃到后碎屑约320ms消散，分数约250ms弹动、400ms高亮。 |
| 获得一颗星 | 第5／10／15分触发5个装饰性小骨头依次飞向星位，单个300ms、间隔60ms；最后一个落下点亮并弹动约300ms，不额外增加分数。 |
| 星星和新增障碍 | 已点亮星星周期性短扫光，三颗错开；新增障碍闪烁约900ms提示，不因此延后碰撞生效。 |
| 碰撞 | 场地短震动约320ms，角色闪烁、头部眩晕符号、碰撞处高亮；0.9秒后结算。三类碰撞共用结果布局，不写失败原因。 |

交付：独立Pixso文档的可编辑画板、组件状态、尺寸标注、字体及色板、导出清单；画板名称在屏幕外。页面与状态按第4章清单交付。

制作可延长的 Doe 侧面腊肠狗：可见四只脚，前脚锚定头部、后脚锚定尾部，直行拉长时两对脚间距增加。头尾不放大、脚不增多；部件四向使用时保持轮廓和接口可读。

| A09 眩晕符号 | 6×6 | 1张像素小星或眩晕标记，供程序绕头部运动；不需画整段轨迹动画。 |

### 拼接与动画验收

- 以上尺寸均为240×240屏幕中的最终像素。角色格块逻辑范围20×20；脚层可四边各超出2像素，中心锚点(12,12)，不改变碰撞范围。

- 以朝右为基准交付，附旋转、镜像后的四向拼接校验图，覆盖直线、连续转角、头接弯角、尾接弯角。接口坐标和透明区须在源文件标明。

- 移动时前后脚错相循环，每格移动分4段切换姿态；暂停和倒计时使用站立帧。

- 不额外交付任意长度的完整狗、每个方向的整身动画、食物飞行整段动画、碰撞闪色整段序列；这些由部件拼接和程序驱动。

### 交付格式

可编辑像素源文件＋透明PNG单帧，原生1倍导出，无抗锯齿、无模糊缩放、无JPEG、无烘焙扫描线或机壳。以asset_id与帧序号命名；附资源清单，记录画布、锚点、方向、帧顺序和循环方式。20×20是正式交付基准，程序负责导入适配。UI图标、字体、面板归第5章，不混入游戏角色资源。

## 7 音频需求 BGM与音效

本章交付给作曲、音效和音频程序。声音应有清晰的复古街机音色，旋律轻快、可长时间循环；提示音易辨认，避免持续尖锐高频。走路和普通转向不播放音效，避免快速连按形成噪声。

### BGM制作与播放

- 制作1首无缝循环BGM，建议20–40秒，无长开场和强收尾。升档复用同一首，无需逐档制作独立曲目。

- 基础播放速度100%，每升一档增加4%，LV8为128%；音乐在100%–128%范围内保持清晰。程序按目标音频方案实现变速。

- 只在局内移动时播放；倒计时、入口、说明和结果页不播放。暂停和结束确认时暂停，恢复后续播；一局结束停止，重开在下一次GO结束后从头播放。

- BGM独立增益初值为25%，音效保留100%，允许后续真机微调。此处是相对线性增益，不等于主观响度25%；不把低音量直接烘焙进母带。

### 音效清单

| ID及事件 | 建议时长 | 制作与触发要求 |
| --- | --- | --- |
| S01 吃到骨头 | 50–150ms | 短促上扬，听感轻快；每根一次。与升档或得星重叠时不叠加单独吃骨声。 |
| S02 倒计时 | 约90ms | 3、2、1共用，同步每次数字切换。 |
| S03 GO | 约330ms | 比倒计时更明亮，明确开始；GO出现时播放。 |
| S04 升档 | 500–900ms | 短上行音型；非得星升档时播放，不应遮蔽后续操作提示。 |
| S05 得星 | 约900ms | 骨头入星位时逐步上扬，最后明亮收束；与5个飞入节奏同步，提供分段时间标注。 |
| S06 碰撞结束 | 约560ms | 清晰失败反馈但不过分刺耳；墙、石头和自身碰撞共用。 |
| S07 暂停与继续 | 约100ms | 短提示，两次状态切换可复用同一资源。 |

### 混音与交付

音效优先于BGM，同帧事件优先级为碰撞结束 > 得星 > 升档 > 吃骨头。BGM让位后按原时间线继续，不每次从头播放。主动结束不播放碰撞音；新纪录使用结果页视觉反馈，无需单独制作音乐。

交付单声道44.1kHz、16-bit PCM WAV及音频源工程；BGM另附MIDI或音高/时值事件表，标注循环点、分段触发点和基础速度。WAV为母版，事件表供合成播放适配；程序根据硬件能力确定运行格式与内存预算。所有文件无削波，首尾无爆音，循环接缝不可闻。
