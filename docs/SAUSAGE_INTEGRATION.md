# Sausage Snake 接入说明

## 当前交付：V1.4 节拍转向（2026-10-20）

每个自动移动节拍只接受第一次确认键按下，锁定下一步右转90°。本节拍后续按下忽略、不累计、不排队；长按不跨节拍重复。按下时不转身、不移动、不重置移动计时，到原定时间才右转并前进；不按则直行。狗头与前脚随实际移动一起转向。不能再原地三连按左转；连续三拍右转会走过三个格子。

保留每两根骨头增长一格、原有速度分档、障碍和奖励配置。统一暂停菜单、结果页返回及俐方体11号字体也已包含在本次交付。角色、骨头、障碍、地块素材未替换。

[飞书当前 PRD](https://vcnz89wpi7j4.feishu.cn/wiki/JKSCwKYQEikpt3kNUgScSt84ndh)保留修订痕迹；仓库内的[2026-10-20 PRD 快照](../设计交付/SausageSnake-无尽版PRD/SausageSnake_无尽版_PRD_20261020.md)省略删除线旧文，配图和视频请查看飞书。旧版文档、设计截图与 Release 仅作历史参考。

## 只接规则

`core/games/sausage.c`、`sausage.h` 仅依赖 C 标准库。

1. `sausage_init(&game, seed)` 开始全新对局，含倒计时。
2. `sausage_step(&game, dt_ms)` 推进时间，暂停时不推进规则。
3. 收到确认键的 `INPUT_EVT_PRESS` 调用 `sausage_turn(&game)`。返回 true 表示本节拍锁定右转；false 表示该状态不接受转向，或本节拍已锁定。松开、长按提示不调用转向。
4. `sausage_next_dir()` 为下一步已锁定方向，`game.dir` 为实际方向。绘制狗头、前脚使用 `game.dir`，不画局内箭头。移动后开始接受下一节拍的输入。
5. 页面层打开统一暂停菜单时调用 `sausage_toggle_pause()`；关闭后恢复完整移动等待时间，已锁定方向保留。菜单、倒计时、结果页不缓存转向输入。
6. 选择结束本局后调用 `sausage_quit()`。结束时按 `bones/end` 展示结果，用 `sausage_reward(bones)` 取得奖励；入账与持久化由主项目负责。

按键映射：蓝色确认键=B，白色选择键=A，黄色返回键=C。玩家界面不显示字母编号。本游戏不处理长按返回，长按松开不补发短按。

## 接完整页面

从主项目页面栈 `page_push(&page_sausage_entry, NULL)` 进入。`page_sausage_entry`、`page_sausage_help`、`page_sausage` 通过 replace 切换。

- 对局中选择键与短按返回均打开同一“已暂停”菜单：选择键进入默认继续，返回键进入默认结束。菜单内选择键切换、确认键执行、返回键取消。结束后直接结算，无第二层确认。
- 倒计时中短按返回也打开同一菜单，默认结束；取消后接着剩余倒计时。对局恢复则等待完整移动间隔。
- 结果页选择键切换“再来一局／返回入口”，确认键执行，返回键直接回入口。800ms保护期仅限制确认键。

需要对接的服务：

- LVGL 9.6.0、`lv_conf.h`、`ui_theme` 和页面管理。无尽版使用 `font_sausage_12/24` 字库，源文件及许可证在 `tools/fonts/Cubic_11*`；`gen_fonts.sh` 可重新生成，避免漏带独立字库。
- `sprite`、`snake_art`、`game_art`、`snake_ui` 共用绘制依赖。不因名称含 snake 而漏带，也不要求引入其他小游戏规则。
- 按下沿输入、单调时钟、页面销毁时的定时器和声音清理。
- `ui_sfx`、`hal_audio`：音乐和音效是代码内音符序列，模拟器实时生成方波，无独立 MP3/WAV。实机需适配音频输出，BGM独立增益为25%。
- `ui_records`、`APP_EVT_BEST_SCORE`：进入读取历史纪录，结算时严格超过才更新，重启保留。
- `APP_CMD_GAME_RESULT`：每局提交一次 `GAME_SAUSAGE` 的分数、星级、贝壳、神值；主项目实际入账并防重复。当前原型收到消息不等于主项目账户到账。

`GameId` 涉及持久化编号，主项目接入时先映射，不随意变更旧存档编号。`pages.h` 合并需要的声明即可，不要求复制其他小游戏。

## 待程序确认：空闲策略

主项目全局空闲看门狗需单独适配。产品建议：入口沿用主项目策略；玩法说明页30秒无操作回客厅；倒计时、对局、统一暂停菜单和结果页保持亮屏，不因无操作退出或软关机。最终时长、范围与实现方式待评审确认。此交付尚未改动本地说明页10秒超时；不能把页面配置当作已完成主项目全局适配。

## 奖励与验证

0–4／5–9／10–14／15+骨头对应0／1／2／3星，贝壳5／10／20／30，神值为星数；主动结束也按当前成绩结算。

先跑 `handoff/test_rules.sh` 或小包内 `test_rules.sh`。页面输入集成测试为 `tests/run_sausage_controls.py`（先构建普通模拟器）。重点核对同拍连按只转一次、长按不跨拍重复、松开后新节拍可再转、头脚在移动时才转向、暂停恢复保留待执行转向、尾格碰撞、障碍生成、单次奖励及纪录保存。原有障碍公平检查未证明所有位置都适合只能右转的路线，需真机试玩验证。

本交付可供复用评估，仍需主项目提供公共服务和硬件适配，不是免适配插件。
