# Sausage Snake 接入说明

## 本次交付

无尽版：每次有效 B 按下，所选方向顺时针转90°；没有次数上限，不忽略反向选择。自动移动到时按当前所选方向走一格，进入身体时正常自撞。每两根骨头增长一格，速度、障碍和奖励沿用 PRD V1.3。

本次只整理交付副本，没有重构原工程。包内游戏素材、游戏源文件与当前项目相同；正式资产规格见 PRD，不以占位素材作为制作要求。

## 只接规则

拷贝 `core/games/sausage.c`、`sausage.h`，仅依赖 C 标准库。

1. `sausage_init(&game, seed)` 开始新局，包含倒计时。
2. `sausage_step(&game, dt_ms)` 推进毫秒时间；暂停时不推进规则。
3. 收到 B 的 `INPUT_EVT_PRESS` 调用 `sausage_turn(&game)`；松开或长按提示不要再次转向。
4. `sausage_next_dir()` 取当前所选方向画箭头；`game.dir` 为最后实际移动方向，用于身体拼接。
5. A 调用 `sausage_toggle_pause()`；结束确认通过后调用 `sausage_quit()`。
6. `game.phase == SAUSAGE_PHASE_OVER` 时读取 `bones/end`，调用 `sausage_reward(bones)` 取得奖励。奖励到账和存档由主项目负责。

暂停继续会重置完整移动等待时间；结束确认的冻结与取消由页面层管理。不要每次按 B 重置移动计时或额外移动。

## 接完整页面

入口为 `page_sausage_entry`，用主项目页面栈 `page_push(&page_sausage_entry, NULL)` 打开。`page_sausage_help`、`page_sausage` 使用同一页面管理协议，三页通过 replace 切换。

需要以下服务，包内提供原工程实现供参照：

- LVGL 9.6.0、`lv_conf.h`、12/24 像素字库及 `ui_theme`。
- `page_mgr` 页面生命周期、输入分发、销毁定时器、回上层。
- 输入事件：B 按下沿转向，A 按下沿暂停/继续，C 短按走页面现有退出流程。入口/说明/结果的确认键按原页面事件处理。
- `sprite`、`snake_art`、`game_art` 和 `snake_ui` 公共图标创建器；不要因名称包含 snake 就漏带依赖，也不要顺便复制三关游戏规则。
- `ui_sfx` 与 `hal_audio`，BGM 维持独立25%增益。
- `hal_clock`，同一局使用单调时间，取消确认后不补走冻结时间。
- `ui_records` 与 `APP_EVT_BEST_SCORE`，提供本游戏历史最高分。
- `APP_CMD_GAME_RESULT` 消息通道，页面提交 `GAME_SAUSAGE` 的分数、星级、贝壳和神值。原工程每局只提交一次，主项目也应防止重复入账。

`GameId` 在当前工程为持久化编号，合并到主项目时先做编号映射，不能随意改变已有游戏存档编号。包内 `pages.h` 含主工程其他页面声明，主项目合并声明，不要求复制所有游戏页面。

## 结果与记录

0–4 / 5–9 / 10–14 / 15+ 骨头分别为0/1/2/3星，贝壳5/10/20/30，神为星数；主动结束按当前成绩结算。最高纪录严格超过才更新，正常结算落盘。原 `app_msg.h` 的通用结构注释不替代本游戏具体退出结算行为，以页面和 PRD 为准。

## 集成验证

先运行规则测试，再验证：B 每次有效按下都更新箭头、长按一次、反向实际碰撞才结束、按键不延后移动、暂停恢复、退出确认取消、身体增长与尾格碰撞、逐档障碍、最高纪录和单次奖励。最后以240×240、1.54英寸目标屏幕验证阅读、输入与音频。
