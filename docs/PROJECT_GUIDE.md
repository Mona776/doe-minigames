# 代码与交付边界

## 目录

- `core/games/`：各小游戏纯 C 规则，独立于 LVGL/SDL/硬件。
- `ui/pages/`：页面生命周期、输入响应、绘制与反馈。Sausage Snake 使用 `page_sausage*.c`。
- `ui/`：公共页面管理、字体、绘制、音频事件、最高纪录缓存。
- `input/`：消抖、按下沿、长按和输入事件。
- `hal/`：时钟、音频、输入、文件系统等平台接口声明。
- `platform/mac/`：SDL 窗口、键盘、文件系统、音频和单线程消息队列。
- `platform/freertos/`：Mac FreeRTOS 任务版模拟器，仍依赖 Mac 平台适配；不是芯片固件。
- `platform/pico/`：Pico 真实硬件驱动和任务入口。
- `assets/generated/`：字体等生成资源；`tools/fonts/` 保留字体源文件与授权。
- `lvgl/`：当前工程自带 LVGL 9.6.0 源码快照；按该快照验证，不承诺任意 LVGL 版本兼容。
- `设计交付/`：PRD 和历史设计稿。正式接入以最新 PRD 为准。
- `handoff/`：模块清单、交付包、规则测试脚本和真机依赖初始化脚本。

## 两种交付用途

完整工程可用于体验、调试和对照集成。Sausage Snake 小包用于提取规则、页面与共用依赖；它不是独立 App，也不是复制两个文件就能编译的组件。

小包的 `src/` 保持原路径和文件内容，`manifest.json` 列出角色分类与 SHA-256。`shared-reference` 分类用于参照或复用；主项目已有对应能力时适配接口，避免重复引入第二套页面管理、存档、输入或奖励服务。

## 第三方依赖

LVGL 及字体随源码保留原许可证。固件依赖以 Git submodule 固定提交，`handoff/firmware-dependencies.json` 同时支持源码 ZIP 下载后的初始化。不要把 SDK 或系统库的“最新版”当作本次验证版本。

## 已知接入事项

- 原型素材需按正式资源需求替换，当前交付不宣称资产已正式验收。
- 硬件引脚、显示刷新、音频输出、任务栈与堆预算需目标板验证。
- `run_tests.sh` 是原工程脚本，其新目录默认 CMake 目标受缓存影响；交付验证使用不依赖构建缓存的 `handoff/test_rules.sh`。
- 累计分数/步数使用当前规则中的整数类型，长期极限运行不在本次交付验证范围内。
